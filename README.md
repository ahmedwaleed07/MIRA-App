# MIRA

MIRA is a global offers and shopping discovery app.

## Locked visual reference
The approved Welcome / Onboarding screen is the visual source of truth. Do not redesign or restyle it unless explicitly requested by the project owner.

## Current prototype
The interactive web prototype lives in `docs/index.html` and is intended to be published with GitHub Pages.

## Core flow
- Language: English, Arabic, Spanish, Russian, Turkish
- Sign In / Sign Up / Continue as Guest
- Phone or email authentication
- Phone country picker with flag + international dialing code
- OTP verification
- Shopping country selection
- All country or selected cities/states
- Saved user shopping preferences with editable location filters
